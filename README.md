# Ocenoid

Multiplayer ocean survival sandbox game.

## Current direction

- 4-player LAN multiplayer
- Shared starting boat in the ocean
- Resource gathering from ocean, underwater areas, and islands
- Modular crafting and construction
- Structures composed from real resources
- Island NPC settlements and trading
- Future NPC decision-making and dynamic economy
- Stylized, lightweight 3D characters and environments

## Current milestone

Phase 0/1: project foundation and character/world prototyping.
